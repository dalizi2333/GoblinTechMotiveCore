# Public Skills Documentation

This directory contains public skill documentation that can be referenced by both AI agents and human developers.

## Structure

Each skill should be a separate Markdown file:

```
docs/skills/
├── skill-name.md
├── another-skill.md
└── ...
```

## Migration

To migrate a private skill from `.trae/skills/` to this public directory, use the `dev-documentation-link` skill.
